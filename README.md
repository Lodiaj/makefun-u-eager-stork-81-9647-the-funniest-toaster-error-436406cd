The Funniest Toaster Error Message — one line, 87 characters, the error message a kitchen toaster shows its owner when something goes wrong:

> ERROR 404: BREAD NOT FOUND. Please insert bread and stop staring at me like I did this.

## Run it

```sh
node main.ts
```

`main.ts` validates the line (1–120 characters and bytes, single line, printable ASCII, at least 3 words, must read like an error message about a toaster) and writes it to `/output/entry.txt`, then verifies the written file round-trips byte-for-byte.
